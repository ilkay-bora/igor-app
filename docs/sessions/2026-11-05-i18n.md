# 2026-11-05: English UI (TR/EN)

Item 2 of "Before going public" in the roadmap.

## How it works

- Turkish stays the source language. Every UI string is wrapped in `t("...")`; the Turkish text is the key into `src/lib/i18n-en.ts`. Missing keys fall back to Turkish, so nothing renders empty. Placeholders: `t("{n} klip", { n })`.
- The language is an install-wide setting (`language` in `data/settings.json`, else the system locale). The root layout (now `force-dynamic`) reads it, sets `<html lang>`, and `LanguageProvider` sets it in `lib/i18n.ts` before children render, so `t()` works anywhere at render or event time without a hook. Changing language saves the setting and reloads.
- Server code (route handlers, `*-server.ts`, projects, render) uses `tServer()` from `lib/i18n-server.ts`, so API errors shown in the UI follow the language too.
- Module-level label constants (models, transitions, ratios, motions, voice tones in `providers.ts`) stay Turkish and are translated where displayed (`{t(m.label)}`).
- Switch: TR/EN toggle in the top bar, and a Language section at the top of Settings and the first-run setup.
- Desktop shell (tray menu, dialogs, splash) reads the same setting.

## Related changes

- Inter loads the `latin-ext` subset (Turkish ğ ş ı İ were falling back to another font).
- Dates and times use the UI language's locale.
- Strip text is uppercased with Turkish rules only when the text itself has Turkish letters (ğ ş ı İ), so English strips don't get a dotted İ and preview and render always agree.
- TTS style presets send English instructions in the English UI.

## Tooling

- `node scripts/i18n/keys.cjs` counts translation keys and missing English entries (`--list` prints them, `--unused` prints stale entries). The 56 "missing" keys today are pass-through: voice names, file names, code.
- The wrapping was done with one-off AST codemods (TypeScript compiler API), then reviewed with screenshots of every page in both languages; the codemods were not kept.

## Verified

- Every page screenshotted in English and Turkish (create, video, editor, voice, compare, settings, ComfyUI guide, errors, setup), no page errors, `<html lang>` correct.
- `data/settings.json` and `data/editor-draft.json` backed up before and restored byte-identical after.
