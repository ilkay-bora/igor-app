# 2026-11-05: MCP server MVP

Item 1 of "Before going public" in the roadmap.

## Studio side

- `lib/editor-schema.ts`: the editor's document types (`EditorDraft`, `TimelineClip`, layers) moved out of the editor page, plus `draftToRenderParams()`, now shared by the editor's render button and agent renders.
- `lib/projects.ts`: saved projects in `data/projects/<id>.json` (`{ id, name, version: 1, draft }`, the draft is the editor's own shape). Create, list, get, rename, delete, `addClip`, `removeClip`, `addText`, with validation (sources only from `/videos/` or `/generated/`, existing files, known transitions/motions, colors).
- Stills added as clips are turned into short MP4s (`/videos/still-<uuid>.mp4`, fitted to the project frame, silent audio), because the editor previews the timeline on a `<video>` element and showed image clips as black.
- `lib/generations.ts`: gallery save logic out of `/api/save`, reused by `POST /api/images` (generate with flux-schnell / flux-dev / gemini, save, return the record).
- New routes: `/api/projects`, `/api/projects/[id]`, `/api/projects/[id]/clips`, `/api/projects/[id]/texts`, `/api/projects/[id]/render`, `GET /api/editor-projects/[id]` (render status), `/api/images`.
- `proxy.ts` accepts `Authorization: Bearer <token>`; unauthorized `/api/*` calls get a 401 JSON instead of a login redirect.
- Editor opens `/video/editor?project=<id>` into its draft, asking first if the current draft has content (guarded against dev's double effect run).
- Desktop shell writes `%APPDATA%/@igor/desktop/server.json` (url, token, pid, studioDir) while running, removed on quit.

## Fix found on the way

- Renders from image sources came out as H.264 High 4:4:4 (`yuv444p`), which many phones and browsers can't play. All libx264 encodes in `editor-render.ts` now use `-pix_fmt yuv420p`.

## packages/mcp (igor-mcp)

- Stdio server on `@modelcontextprotocol/sdk` 1.32 + zod 4. Plain ESM JS, no build step.
- Connection: `IGOR_URL`/`IGOR_TOKEN`, else desktop `server.json` (pid checked), else `localhost:3000` with `.env.local` `APP_TOKEN` or `data/local-token`. Resolved per call, so IGOR can start after the agent.
- Tools: `generate_image`, `list_media`, `list_projects`, `create_project`, `get_project`, `add_clip`, `remove_clip`, `add_text`, `render_project` (waits by default, returns the MP4 file path), `get_render`, `open_in_editor`.
- Progress heartbeat every 10 s when the client sends a progress token: a cold ComfyUI start plus first FLUX load took ~75 s, past the SDK client's 60 s default.

## Verified

- End to end through a real MCP client: list media, create a 720x1280 project, add clips with a transition, add a caption, reject a `/../` source, render (2.5 s for 4 s of stills), open link.
- `generate_image` with local FLUX schnell (cold ~75 s, warm ~15-40 s); heartbeat kept an 11 s-timeout client waiting 43 s.
- Headless editor open with `?project=`: one confirm, clips play in preview, caption in Inter. The real `data/editor-draft.json` was backed up and restored byte-identical (sha1 checked).
- Test renders, projects, images and still clips deleted afterwards; ComfyUI and the dev server stopped.
